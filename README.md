# OHT·로봇 이벤트 재생 및 상태 스냅샷 생성기

시간순 상태 재생과 장비별 버전 중복 제거로 재현 가능한 트윈 상태를 만듭니다.

- 분야: XR/디지털 트윈
- 요구 사항: Python 3.10 이상, 외부 패키지와 API 키 불필요
- 샘플: `events.json` (합성 데이터 또는 공개 논문 메타데이터)

## 실행

저장소 루트에서 실행합니다.

```bash
python main.py --html demo.html
```

## 동작과 입출력

events.json 입력 후 JSON 상태와 HTML을 출력합니다. --until 2026-10-08T06:00:01Z 를 지정하면 해당 시점 스냅샷을 생성합니다.

## 설계 판단

AI 출력을 곧바로 장비 동작으로 연결하기 전에 입력 품질, 상태 버전, 모델 적용 범위를 검증해야 한다는 개발자 관점을 적용했습니다. [논문·설계 분석](TRENDS.md)은 공개 원문 자료와 구현자의 해석을 분리합니다.

## 한계

3D 렌더링·Unity 런타임·실시간 통신은 포함하지 않습니다. UTC 고정 형식과 동일 좌표계를 전제로 합니다. 장비 재부팅에 따른 버전 초기화는 별도 세션 ID 확장이 필요합니다.
